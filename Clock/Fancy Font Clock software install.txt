STEP 1: Install WiringPi

  sudo apt-get update

  sudo apt install git
    Do you want to continue? [Y/n] y

  git clone https://github.com/WiringPi/WiringPi

  cd WiringPi

  ./build

  gpio -v

STEP 2: Transfer Fancy Font Clock files to Raspberry Pi

  Using an SSH file transfer app (I recommend WinSCP), login to the Raspberry Pi

  On the SSH app, copy the "Clock" directory to the Raspberry Pi "/home/pi/" directory

  On the SSH app, navigate to the Raspberry Pi "/home/pi/Clock/Code/" directory

  On the SSH app, right-click on the "clock" file
  and select "Properties"

  On the SSH app, in the "Permissions:" section enable "X" for: Owner, Group, and Others

STEP 3: AutoStart Fancy Font Clock at boot

  sudo nano /home/pi/.bashrc

    Add at the end:
      cd /home/pi/Clock/Code
      sudo ./clock

    Ctrl-X
      Save modified buffer?
        y

STEP 4: Reboot

  sudo reboot
