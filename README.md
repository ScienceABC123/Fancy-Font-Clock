# Fancy-Font-Clock

The Fancy Font Clock (v2.0) is a digital clock that displays the time/date using truetype style
bit-mapped fonts instead of the seven-segment display used by most digital clocks. It gets the
time/date information from your WiFi. As such it automatically adjusts for daylight/standard time
changes per your WiFi service provider. Version 2.0 includes software changes to overcome a C
programming language limitation when multiple time structures are used (GMT and local), more control
over display brightness, and better auto-dimming at night.
